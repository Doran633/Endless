# v1.5.3 Deployment Assets Report

## 1. 本阶段工程效果

本阶段将 v1.5.2 的 VPS 部署规划落成可复用部署资产。项目现在有 Nginx 示例配置、systemd 服务模板和一份面向 Ubuntu VPS 的部署步骤文档。

本阶段没有新增 AI 业务功能，没有修改 RAG 主链路，也没有修改数据库结构。

## 2. 新增文件职责

- `deploy/nginx/beichen-agent.conf.example`：Nginx 示例配置，用于前端静态文件托管和 FastAPI 反向代理。
- `deploy/systemd/beichen-agent.service.example`：systemd 服务模板，用于守护 FastAPI 后端进程。
- `docs/deployment_guide.md`：完整 VPS 部署指南，覆盖目录结构、环境变量、前端构建、后端运行、Nginx、HTTPS、备份、更新和回滚。
- `docs/v1.5_deployment_assets_report.md`：本阶段报告。

## 3. Nginx 配置如何工作

Nginx 在生产部署中位于浏览器和 FastAPI 之间：

```text
Browser -> Nginx -> frontend_dist
Browser -> Nginx /api -> FastAPI 127.0.0.1:8000
```

具体职责：

- `/`：读取 `/opt/beichen-agent/frontend_dist`，返回 React/Vite 构建后的静态页面。
- `/api/`：转发给 FastAPI 的 `/api/` 路由。
- `/health`：转发给 FastAPI 健康检查接口。
- `try_files $uri $uri/ /index.html`：保证 React 单页应用刷新时不会 404。
- `client_max_body_size 25m`：允许文件上传请求通过 Nginx。

Nginx 不暴露 `runtime/data`、`runtime/uploads` 或 `runtime/vector_store`，避免数据库、上传文件和文档 chunk 索引被公网直接访问。

## 4. systemd 如何守护 FastAPI

systemd 模板会让 FastAPI 作为后台服务运行：

- `WorkingDirectory` 指向后端目录。
- `EnvironmentFile` 指向生产环境变量文件。
- `ExecStart` 使用虚拟环境里的 Python 启动 Uvicorn。
- `Restart=on-failure` 让后端异常退出后自动重启。
- `StandardOutput` 和 `StandardError` 写入固定日志文件。

这样服务器重启后可以自动启动后端，也方便用 `systemctl status` 和 `journalctl` 排查问题。

## 5. 生产环境变量如何放置

生产环境变量建议放在：

```text
/opt/beichen-agent/runtime/backend.env
```

这个文件不在 Git 项目目录内，里面保存真实 API Key、真实访问口令、SQLite 路径、uploads 路径和 vector_store 路径。

部署时必须保证：

- 不提交真实 API Key。
- 不提交真实访问口令。
- 不把 `runtime/` 暴露为 Nginx 静态目录。
- `DATABASE_PATH`、`UPLOAD_DIR`、`VECTOR_STORE_DIR` 指向持久化目录。

## 6. 部署更新流程

推荐更新流程：

1. 本地提交并推送 Git。
2. SSH 登录服务器。
3. 备份 `/opt/beichen-agent/runtime`。
4. 在服务器 `git pull`。
5. 安装后端依赖。
6. 运行后端编译检查。
7. 安装前端依赖并 `npm run build`。
8. 复制 `dist` 到 `/opt/beichen-agent/frontend_dist`。
9. 重启 `beichen-agent` systemd 服务。
10. 检查 Nginx 配置并 reload。
11. 访问域名手动验收。

## 7. 安全边界

本阶段仍然是 MVP 部署资产，不是完整生产安全方案：

- 没有正式用户系统。
- 没有多用户权限隔离。
- 没有请求限流。
- 没有管理员后台。
- 没有数据库迁移系统。
- SQLite、本地 uploads 和本地 vector_store 仍然是单机持久化。

因此当前部署方式适合个人项目、可信任小范围试用，不适合公开高流量服务。
