# v1.1.3 轻量 UI 丰富与文件中心体验优化报告

## 1. 本次完成内容

v1.1.3 在不修改后端、不修改数据库、不改变 RAG 主链路的前提下，对现有前端界面做了一次轻量产品化优化。

本次完成：

- 文件中心顶部新增状态概览区。
- 文件上传区域从简单拖拽框优化为更像工作台的上传组件。
- 文件状态标签增加更清晰的用户说明。
- 文件列表可读性增强，减少纯工程说明感。
- 文件中心空状态增加更明确的上传引导。
- 聊天输入区当前 RAG 文件提示更自然。
- RAG 回答引用 chunks 展示改为“参考片段”。
- 降低 score 等工程字段的视觉权重。

本次没有实现：

- 新后端 API。
- 新数据库字段。
- RAG 主链路修改。
- 文件中心自动处理。
- 文件删除 API。
- 聊天会话持久化。
- Agent、多文件 RAG、企业权限。

## 2. UI 丰富思路

本次 UI 优化的原则是：**增强信息表达，不扩展产品范围**。

具体判断：

- 用概览区帮助用户快速理解当前文件状态。
- 用更清楚的上传区解释支持格式和后续处理路径。
- 用面向用户的状态文案替代过多工程词。
- 保留现有“对话 + 文件中心”结构。
- 不增加未实现功能入口。
- 不做大型首页、复杂动效或主题系统。

这让北辰agent 更像一个成熟的 AI 工作台，但不会让项目范围膨胀。

- 空状态增加上传引导。
- 检索、问答、预览弹窗文案更偏产品表达。

职责：

- 展示文件管理页面。
- 触发已有上传、解析、切块、向量化、索引、检索和问答操作。
- 不直接处理业务逻辑。

### `frontend/src/components/ChatInput.tsx`

修改内容：

- 文件已完成处理时提示“可以基于该文件提问”。
- 提示条样式更轻、更像状态说明。

职责：

- 负责聊天输入。
- 负责聊天侧文件上传入口。

### `frontend/src/components/MessageBubble.tsx`

- RAG 引用区域从“引用片段”优化为“参考片段”。

职责：

- 渲染 RAG 回答中的来源依据。

## 4. 视觉优化

本次视觉优化包括：

- 文件中心顶部统计卡片。
- 上传区视觉层次、图标、按钮和说明文案。

这些优化不改变业务流程，只提升信息组织和第一眼质感。

## 5. 交互优化

本次有轻量交互表达优化：

- 文件中心打开后仍加载后端文件列表。
- 上传区仍保持原有上传行为。
- 手动解析、切块、向量化、索引按钮仍保留。
- 聊天侧绑定文件提示更明确。
- RAG 回答的引用依据更容易被用户理解。

没有改变：

- 文件中心上传后仍不自动处理。
- 聊天侧上传自动处理逻辑不变。
- 普通聊天和 RAG 问答切换逻辑不变。
