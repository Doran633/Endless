# v1.5.4 Invite Code Access Report

## 1. 工程效果

本阶段将原来的单个 `APP_ACCESS_PASSWORD` 扩展为多个 6 位数字邀请码。部署或小范围试用时，可以在 `backend/.env` 中配置多个邀请码，前端用户输入任意一个有效邀请码后，即可调用 `/api/v1/*`。

本阶段不新增 AI 业务功能，不修改 RAG 主链路，不修改数据库结构。

## 2. 修改文件职责

- `backend/app/core/config.py`：新增 `APP_INVITE_CODES` 读取逻辑，只保留 6 位数字邀请码。
- `backend/app/core/access_control.py`：访问保护中间件优先校验邀请码列表，并保留旧 `APP_ACCESS_PASSWORD` 兼容。
- `backend/.env.example`：新增 `APP_INVITE_CODES=` 示例字段，不包含真实邀请码。
- `frontend/src/components/LoginPage.tsx`：入口页文案从访问口令调整为邀请码。
- `README.md`：补充邀请码配置说明。
- `docs/status.md`：同步当前阶段状态。

## 3. 邀请码校验调用链

```text
LoginPage 输入邀请码
-> setAccessPassword() 保存到 localStorage
-> fetchWithAccess() 读取本地邀请码
-> 请求头 X-Beichen-Access
-> FastAPI access_control_middleware
-> settings.app_invite_codes / settings.app_access_password
-> 放行或返回 401
```

前端内部仍复用原来的 `fetchWithAccess()` 和 localStorage key，这是为了减少迁移范围。对用户来说，展示文案已经是“邀请码”。

## 4. APP_INVITE_CODES 和 APP_ACCESS_PASSWORD 的兼容关系

优先级：

1. 如果 `APP_INVITE_CODES` 非空，优先使用邀请码列表。
2. 如果 `APP_INVITE_CODES` 为空但 `APP_ACCESS_PASSWORD` 非空，继续使用旧单口令模式。
3. 如果两者都为空，本地开发不启用访问保护。

示例：

```env
APP_INVITE_CODES=123456,654321
APP_ACCESS_PASSWORD=
APP_ACCESS_HEADER=X-Beichen-Access
```

旧兼容：

```env
APP_INVITE_CODES=
APP_ACCESS_PASSWORD=123456
APP_ACCESS_HEADER=X-Beichen-Access
```

## 5. 为什么这仍不是正式登录系统

邀请码只是共享门禁，不是身份系统。它没有用户表、密码哈希、注册登录、JWT、session cookie、多用户权限隔离、文件和会话的用户级隔离、邀请码使用次数和审计记录。

它适合个人 MVP、小范围可信任试用，不适合公开高流量生产服务。

## 6. 测试方法

后端行为：

- `APP_INVITE_CODES=` 且 `APP_ACCESS_PASSWORD=`：`/api/v1/*` 放行。
- `APP_INVITE_CODES=123456,654321`：无邀请码或错误邀请码返回 `401`。
- `APP_INVITE_CODES=123456,654321`：正确邀请码放行。
- `APP_INVITE_CODES=abc,12345,123456`：只有 `123456` 生效。
- `APP_INVITE_CODES=` 且 `APP_ACCESS_PASSWORD=legacy-pass`：旧单口令仍可用。
- `/health` 不需要邀请码。

验证命令：

- `scripts/check-local.ps1`
- `python -m compileall app`
- `npm exec tsc -- --noEmit`

## 7. 生成多个邀请码

PowerShell 生成 5 个 6 位数字邀请码：

```powershell
1..5 | ForEach-Object { Get-Random -Minimum 100000 -Maximum 1000000 }
```

将结果写入 `backend/.env`：

```env
APP_INVITE_CODES=123456,654321,839204,775421,102938
APP_ACCESS_HEADER=X-Beichen-Access
```

真实邀请码不要写入 GitHub、README、docs 或截图。
